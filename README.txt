SOCIAL SECURITY MEDICAL PROCEDURE CODE SEARCH

This is the final standalone website package. The app displays the K value next to each procedure code when a K value is present in the source workbook.

PUBLISH WITH NETLIFY DROP:
1. Extract social_security_codes_final_site.zip on your laptop.
2. Open https://app.netlify.com/drop
3. Drag the extracted folder (social_security_codes_final_site) onto the Netlify Drop page, or drag the index.html file if prompted.
4. Netlify will publish the site and give you a web address ending in netlify.app.

The website is self-contained in index.html and does not require a server or separate data files.
